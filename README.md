# SkillRAG-CVE

An ongoing multi-agent project that turns vulnerability documentation into reusable skills for controlled local reproduction and verification.

## Workflow
Vulnerability discovery → Documentation analysis → Skill generation → Local reproduction → Verification → Experience reuse

## Current progress
The core workflow has reproduced five vulnerabilities on prepared local targets. Automatic target assembly and startup are still under development.

## Focus
- Coordination between specialized LLM agents.
- Reusable skills derived from vulnerability documentation.
- Verification of reproduction outcomes.
- Experience reuse across tasks.

## Code availability
This repository currently provides a project overview. Implementation code is not yet public.
